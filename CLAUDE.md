# Nevervale Website

## Blog Posts

- **Homepage (index.html)**: Display only the 3 latest blog posts
- **Blog page (blog.html)**: Display ALL blog posts

When adding a new blog post:
1. Create `posts/update-N/index.html` for the full post
2. Add the post to `blog.html` (all posts visible)
3. Add the post to `index.html` and remove the oldest (4th) post to keep only 3 visible
